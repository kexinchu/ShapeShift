# Superseded paper materials

The canonical paper remains [`../ShapeShift-camera-ready.pdf`](../ShapeShift-camera-ready.pdf)
and [`../main.tex`](../main.tex). This archive preserves earlier paper sources
and their original figures for local-workspace recovery, not as a second
current paper or newly verified results.

- `aaai-draft/`: former repository's anonymous AAAI draft, original templates,
  plotting scripts and figures. Its own README describes that historical state.
- `local-plot-entry/`: original working-directory-dependent plot launcher;
  the current `paper/plot_all_figures.py` uses paths relative to its own file.
- `local-author-kit/` (if present): locally supplied AAAI template variants.

No paragraphs, measurements, or graphics were merged into the camera-ready
paper. Conference forms, signatures, submission bundles, talks, private notes,
logs and old private Git history are not included.
