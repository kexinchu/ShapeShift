# Historical experimental artifacts

This directory retains trace builders, benchmark drivers and curated historical
result summaries. The installable reconstructed scheduler is in `../shapeshift/`.
The canonical camera-ready paper is in [`../paper/`](../paper/README.md).

See the [root README](../README.md) for setup and
[reproduction guide](../docs/REPRODUCIBILITY.md) for supported commands and limits.
`data/`, `external/`, and raw generated `results/` are local-only; only the curated
`results/paper/` summaries are versioned. They come from the original runtime,
not the reconstruction.
